# Дела — список задач

Минималистичное адаптивное веб-приложение для личных задач. Работает целиком в браузере, без сервера и сторонних библиотек.

## Запуск

1. Откройте `index.html` в современном браузере.
2. Если браузер ограничивает `localStorage` для файлов `file://`, запустите локальный статический сервер из папки проекта:
   - Python: `python3 -m http.server 8000`
   - затем откройте `http://localhost:8000`.

## Возможности

- Добавление задачи кнопкой или клавишей Enter; пустой ввод не принимается.
- Отметка выполнения, отдельное удаление и фильтры по статусу.
- Счётчики общего числа, оставшихся и выполненных задач и индикатор прогресса.
- Массовое удаление выполненных задач с подтверждением браузера.
- Автоматическое сохранение и восстановление задач через `localStorage`.
- Обработка недоступного/повреждённого хранилища, адаптивная мобильная верстка и поддержка настройки уменьшения анимации.

## Файлы

- `index.html` — структура приложения и доступные элементы управления.
- `styles.css` — оформление, состояния интерфейса, адаптивность и анимации.
- `app.js` — операции со списком, фильтрация и хранение данных.
- `README.md` — эта инструкция.

Данные записываются в `localStorage` браузера под ключом `dela.todo.tasks.v1`. Они остаются на этом устройстве и в этом браузере; очистка данных сайта удалит сохранённый список.
