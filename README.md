# Дела — список задач

Лёгкий адаптивный To-Do List на чистых HTML, CSS и JavaScript. Данные остаются в браузере пользователя — сервер и сборка не требуются.

## Возможности

- Добавление задач кнопкой или клавишей Enter; пустой ввод не принимается.
- Отметка выполнения и удаление отдельных задач.
- Фильтры: все, активные и выполненные.
- Счётчики задач и индикатор прогресса.
- Массовое удаление выполненных задач с подтверждением.
- Автоматическое сохранение и восстановление через `localStorage`.
- Адаптивная вёрстка, анимации и поддержка системной настройки уменьшения движения.
- Обработка ошибок браузерного хранилища.

## Запуск локально

Можно открыть `index.html` в браузере. Если браузер ограничивает `localStorage` для адресов `file://`, используйте локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

## Публикация на GitHub Pages

В репозитории уже добавлен GitHub Actions workflow `.github/workflows/deploy.yml`.

1. Создайте GitHub-репозиторий и отправьте в него файлы проекта.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. После push в ветку `main` workflow соберёт и опубликует сайт. Ссылку на него можно открыть в **Settings → Pages** или во вкладке **Actions**.

Workflow также можно запустить вручную из вкладки **Actions** через **Run workflow**. Для стандартной публикации GitHub Actions использует `GITHUB_TOKEN`; отдельные секреты не нужны.

## Хранение данных

Задачи сохраняются в `localStorage` браузера под ключом `dela.todo.tasks.v1`. Список привязан к конкретному браузеру и устройству; очистка данных сайта удалит его. GitHub Pages не получает доступ к этим данным.
